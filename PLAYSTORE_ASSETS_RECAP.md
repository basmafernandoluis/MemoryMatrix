## 🚀 ÉTAPES DE PUBLICATION

### 1. Créer l'Application
```
Google Play Console > Créer une application
```

### 2. Remplir la Fiche
```
Fiche du Play Store > Tous les onglets
```

### 3. Uploader l'AAB
```
Production > Versions > Créer une version
Uploader: app-release.aab
```

### 4. Configurer le Contenu
```
Stratégie de contenu > Classification du contenu
```

### 5. Soumettre
```
Vérifier la version > Démarrer le déploiement
```
